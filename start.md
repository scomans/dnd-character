### Start

Create an Angular 21 app (using Optimus UI (formerly known as PrimeNG)) for managing my DND character. It should include all fields from the PDF.
All Textboxes should be editable but display the text as formated markdown.
All Inputs should be saved as one big JSON object which can be exported and is saved in localstorage (and maybe on a server in the future).
If an input is computed use the DND 2024 E5 rules.
